# Compêndios — Ordem Paranormal

Os compêndios deste sistema são criados automaticamente pelo Foundry (LevelDB)
na primeira vez que um Mundo com o sistema é carregado, conforme registrados em
`system.json` (`packs` + `packFolders`). Eles aparecem na aba **Compêndios**,
agrupados na pasta **Ordem Paranormal**:

- Poderes, Rituais, Armas, Proteções, Equipamentos, Origens, Trilhas, Condições (Itens)
- Criaturas (Atores)

## Como popular

1. Crie o conteúdo no Mundo (use o assistente **Criar Item** na aba de Itens,
   ou as fichas), ou importe via JSON.
2. Arraste o Item/Ator criado para o compêndio correspondente na aba Compêndios.
3. O conteúdo fica disponível para qualquer Mundo que use o sistema.

> Estes compêndios começam vazios — são o repositório oficial de conteúdo do
> sistema, prontos para receber suas criações.
